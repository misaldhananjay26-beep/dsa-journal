# DSA Journal

A practical data-structures-and-algorithms learning journal with readable solutions, tests, and complexity analysis.

This repository is organized by problem-solving pattern rather than by random daily commits. Each entry should explain the idea clearly enough for a future review.

## Structure

```text
javascript/
  arrays/
      two-sum.js
          two-sum.test.js
          notes/
            template.md
            progress.json
            ```

            ## Problem entry checklist

            - Restate the problem in your own words
            - Explain the chosen pattern
            - Include a readable implementation
            - Add time and space complexity
            - Test normal, boundary, and duplicate-input cases
            - Write one lesson learned
